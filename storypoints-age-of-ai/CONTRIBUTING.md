# Contributing

This repository preserves prospective research records. Changes must not silently rewrite a frozen query, protocol, seed policy, result, appraisal, or closure record.

## Change classes

- documentation correction;
- code maintenance with unchanged scientific behavior;
- new developmental query or simulation scenario;
- versioned protocol amendment;
- new frozen systematic or locked evaluation release.

## Requirements

1. Explain the scientific effect of the change.
2. Add or update tests for code changes.
3. Retain null, adverse, and failed-gate outcomes.
4. Keep restricted data and production seeds outside Git.
5. Use a new version for material protocol changes.
6. Run `make verify` before review.
7. Update claims, citations, manifests, and the Excel ledger when affected.

AI assistance must be disclosed according to venue policy. Human authors remain accountable for correctness and research integrity.
