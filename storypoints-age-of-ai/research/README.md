# Research workspace

This directory separates the research definition from the study evidence:

- [`design/`](design/README.md) contains the numbered concept, protocol,
  framework, construct, simulation-governance, and reconciliation records.
- [`studies/vdcm/`](studies/vdcm/README.md) contains the durable study,
  evidence-map, simulation, integrity, and restricted-material navigation layers.

Executable evidence-review and simulation packages remain at repository root so
their Python imports and verification commands remain stable.
