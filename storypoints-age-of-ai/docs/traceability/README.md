# Traceability Index

This directory is the repository-level navigation layer for provenance and
release decisions. It does not duplicate or replace checksum-bound evidence.

## Canonical records

- [`evidence-preservation-map.md`](evidence-preservation-map.md): maps each
  scientific layer to its authoritative artifacts.
- [`research-status-and-release-path.md`](research-status-and-release-path.md):
  records the completed gates and the remaining manuscript/release sequence.
- [`RESEARCH_DESIGN_RELOCATION_2026-08-20.json`](RESEARCH_DESIGN_RELOCATION_2026-08-20.json):
  maps each former root-level numbered artifact to its checksum-preserving
  canonical location under `research/design/`.
- [`CONTROLLED_FOLDER_RELOCATION_2026-08-20.json`](CONTROLLED_FOLDER_RELOCATION_2026-08-20.json):
  records the approved consolidation of research, study, documentation,
  communication, workbook, image, and status artifacts.
- [`../../research/studies/vdcm/integrity/releases/`](../../research/studies/vdcm/integrity/releases/):
  immutable accountable-author approvals and future release manifests.

Conversation transcripts, credentials, environment files, and restricted data
are not part of this traceability layer.
