# THINKAI developmental result artifacts

The current manuscript-reporting package is
[`developmental_simulation_v2/`](developmental_simulation_v2/). It contains:

- run-cluster bootstrap uncertainty with 5,000 deterministic resamples;
- scenario/model Brier tables;
- a descriptive lowest-Brier summary;
- SVG and 300-DPI PNG versions of the comparator-difference figure; and
- a checksummed reporting manifest tied to the reconciled development inputs.

All outputs are developmental synthetic evidence. They are not empirical,
causal, cognitive-load, organizational, or superiority validation.

`developmental_simulation_v1/` is superseded because its first figure layout
failed visual inspection. Its numerical tables used the same inputs, but it
must not be used in the manuscript.
