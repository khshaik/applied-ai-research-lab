# Data and code availability — working version

The Route B study uses public bibliographic metadata, lawfully accessed source
reports, and synthetic simulation outputs. It contains no restricted
organizational or human-participant dataset.

Subject to source licences, conference double-blind rules, and acceptance, the
intended reproducibility package includes:

- the approved and checksummed evidence-map protocol, literal search queries,
  source control records, study-flow ledger, exclusion reasons, and extraction
  matrix;
- screening and adjudication prompts plus model/version provenance;
- simulation source code, schema, developmental configuration, declared
  development seeds, manifests, comparator outputs, uncertainty tables,
  figures, and parameter-provenance records; and
- claim-verification, AI-assistance, and correction-history records.

Copyrighted full texts will not be redistributed. Links, persistent identifiers,
and lawful-version status will be provided where permitted. The prototype
locked-evaluation seed file is not a confidential production evaluation and is
not used to support manuscript claims. No production locked evaluation is part
of the minimum paper route.

The release location, archival DOI, licence, and availability date remain to be
completed after the conference's anonymity and supplementary-material rules are
confirmed.
