# AI-assistance disclosure — working version

OpenAI ChatGPT/Codex and isolated AI-agent contexts assisted with literature
query engineering, metadata normalization, screening preparation, candidate
extraction, source-location checks, software and protocol critique, code
generation, automated tests, deterministic scientific-diagram code, statistical
report generation, and drafting or revising manuscript language.

AI systems were not treated as authors, human research participants, qualified
practitioner panels, ethics reviewers, or accountable publication decision
makers. Agent agreement is reported, where applicable, as agent concordance and
not as human inter-rater reliability. Synthetic agent ratings are not used to
validate human attention, cognitive load, content validity, usability, or
organizational usefulness.

The accountable human author retains responsibility for:

- protocol and scope decisions;
- lawful source access and every eligibility/appraisal decision;
- opening and checking the exact locator for each material cited claim;
- verifying bibliographic records, numerical results, code, tables, figures,
  alt text, analysis, and interpretation;
- originality, copyright, confidentiality, conflicts of interest, research
  ethics, authorship, and submission declarations; and
- approving the final manuscript and submitted package.

No confidential organizational data or human-participant data are used in the
Route B study. The framework diagrams are deterministic vector outputs from
checked-in plotting code and author-defined scientific content. The simulation
result figure is generated from checksummed synthetic data. AI assistance with
their design and code is included in this disclosure.
