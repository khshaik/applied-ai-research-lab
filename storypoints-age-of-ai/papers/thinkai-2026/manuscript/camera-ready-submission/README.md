# Camera-Ready Submission Starting Package

This directory is the controlled post-acceptance starting package for the
THINKAI 2026 VDCM paper. It is separate from the anonymous initial-submission
package and must not be uploaded as a camera-ready manuscript in its current
form.

## Preserved manuscript baseline

- [`VDCM_ThinkAI2026_CAMERA_READY_STARTING_POINT_v0.2.docx`](VDCM_ThinkAI2026_CAMERA_READY_STARTING_POINT_v0.2.docx)
- [`VDCM_ThinkAI2026_CAMERA_READY_STARTING_POINT_v0.2.pdf`](VDCM_ThinkAI2026_CAMERA_READY_STARTING_POINT_v0.2.pdf)

These files are byte-identical preservation copies of the verified anonymous
v0.2 manuscript. Their content has not been edited, identified, or represented
as a finished camera-ready submission. The binding checksums are recorded in
[`CAMERA_READY_PACKAGE_MANIFEST_v0.2.json`](CAMERA_READY_PACKAGE_MANIFEST_v0.2.json).

## When to use

Use this package only after acceptance and receipt of the authoritative
reviewer and organizer instructions. Create a new version when applying author
identity, declarations, reviewer revisions, or production corrections. Never
overwrite the preserved v0.2 starting pair.

Before release:

1. complete [`KNOWN_UPDATE_GAP.md`](KNOWN_UPDATE_GAP.md);
2. record reviewer responses using
   [`REVIEWER_RESPONSE_TEMPLATE.md`](REVIEWER_RESPONSE_TEMPLATE.md);
3. complete [`CAMERA_READY_CHECKLIST.md`](CAMERA_READY_CHECKLIST.md);
4. obtain the accountable author's G06 approval; and
5. submit only after explicit G07 authorization.

Author metadata must come from
[`../identified-author/AUTHOR_METADATA_TEMPLATE.md`](../identified-author/AUTHOR_METADATA_TEMPLATE.md),
not from repository paths, accounts, document ownership, or inference.
