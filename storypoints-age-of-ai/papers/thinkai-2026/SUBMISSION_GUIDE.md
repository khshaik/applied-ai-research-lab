# THINKAI 2026 Submission Guide

## Package layout

- `manuscript/initial-submission/`: anonymous-review DOCX/PDF and QA record.
- `manuscript/identified-author/`: author-identified DOCX/PDF retained for the
  appropriate venue stage.
- `declarations/`: AI assistance, ethics/responsible use, and data/code
  availability statements.
- `venue/`: authoritative conference requirements and retained source notes.
- `release/`: final release manifest, approval record, and submission receipt.

## Release order

1. Complete and verify the Markdown source.
2. Confirm the authoritative venue template, page limit, anonymization, and
   declaration requirements.
3. Generate both manuscript variants from the same controlled source.
4. Render DOCX to PDF and page images; visually inspect every page.
5. Run citation, DOI, language, duplication-risk, metadata, and anonymity
   checks.
6. Obtain G06 approval.
7. Submit only after explicit G07 authorization.
8. Archive the exact submitted files, hashes, and receipt.
