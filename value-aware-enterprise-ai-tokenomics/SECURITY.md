# Security and Responsible Disclosure

Do not open a public issue containing held-out or investigator-only data, personal information, credentials, private review material, customer telemetry, contract terms, or operational security details.

For a suspected leak, remove public access to the affected branch or release, preserve the Git and hosting audit trail, rotate exposed credentials, and contact the repository owner privately. Do not rewrite a published research record to conceal a scientific result; issue an explicit correction or withdrawal record.

The reference implementation is a research evaluator, not a production authorization or financial-control system. Do not use its lexical authorization classifier for live compliance decisions.
