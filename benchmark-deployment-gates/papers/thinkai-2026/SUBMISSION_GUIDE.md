## Submission Requirements

### Format
- **Page Limit**: 6 pages (strict)
- **Template**: Springer LNCS format
- **File Types**: PDF (for review), DOCX + PDF (camera-ready)
- **Anonymization**: Double-blind review (remove author info, affiliations, acknowledgments)

### Content Requirements
- Abstract (150-200 words)
- Keywords (4-6 terms)
- Introduction with clear problem statement
- Related work / background
- Methodology
- Results with tables/figures
- Discussion
- Conclusion
- References (not counted in page limit)

## Checklist Before Submission

### Content
- [ ] Abstract ≤200 words
- [ ] 4-6 keywords
- [ ] All figures/tables cited in text
- [ ] References formatted per Springer LNCS
- [ ] Page limit ≤6 pages (excluding references)
- [ ] All hypotheses (H1, H2, H3) reported transparently

### Anonymization
- [ ] No author names in PDF
- [ ] No affiliations in PDF
- [ ] No acknowledgments in PDF
- [ ] No self-citations that identify author
- [ ] Repository links removed

### Quality

- [ ] Grammar check complete
- [ ] Figures high-resolution (300 DPI)
- [ ] Tables formatted consistently
- [ ] References complete and accurate

### Files
- [ ] Anonymous PDF generated
- [ ] PDF visually inspected
- [ ] File size <10 MB
- [ ] Filename follows convention
