# Manuscript lifecycle separation

The two child folders represent different publication stages and must not be mixed.

## Initial submission

[`initial-submission/`](initial-submission/) is the review package for the 25 August 2026 deadline. Its manuscript is anonymous in visible content and document metadata. The PDF is the upload candidate; the DOCX is the editable source.

## Camera-ready submission

[`camera-ready-submission/`](camera-ready-submission/) is an identified starting package for use only after acceptance and reviewer revision. It is not the August upload.

## Safety rule

Before any upload, inspect the selected file and filename. An anonymous-review upload must not contain author names, affiliations, email, ORCID, acknowledgements that reveal identity, identifying repository links, or identifying metadata.
