# New Paper Template

Create a new sibling directory under `papers/` and include:

- `README.md`: venue, status, anonymity requirements, and submission dates;
- `manuscript/`: editable source and verified export;
- `declarations/`: authorship, funding, ethics, interests, AI-use, and data/code availability;
- `integrity/`: claim ledger, citation verification, similarity-review record, and artifact manifest;
- `release/`: repository DOI and accepted/camera-ready files only after venue permission.

Link the paper to one or more versioned directories under `studies/`. Do not reuse an exposed test set as confirmatory evidence for a later paper.
