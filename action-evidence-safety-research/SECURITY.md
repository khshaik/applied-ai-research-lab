# Security and Responsible Disclosure

Do not open a public issue containing sealed labels, investigator-only data, personal information, credentials, private review material, or operational security details.

For a suspected data leak, remove public access to the affected branch or release, preserve the Git and hosting audit trail, rotate any exposed credentials, and contact the repository owner privately. Do not rewrite a published research record merely to conceal a scientific result; use an explicit correction or withdrawal record.
